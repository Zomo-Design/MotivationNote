# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue for a vulnerability that could put users or their local data
at risk.

MotivationNote does not use a server or make network requests. Security reports
are still welcome for local data handling, unsafe file operations, code signing,
or dependency/toolchain concerns.
