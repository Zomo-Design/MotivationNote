# 激励便签设计规格

日期：2026-07-31
目标平台：macOS 14 及以上
产品名称：激励便签

## 1. 产品目标

做一个可以常驻 Mac 桌面的原生激励便签。用户把喜欢的激励语长期收藏在“语录库”中，每天从语录库勾选一句或多句，桌面便签按照用户设定的顺序展示当天选中的全部语录。

应用不需要账号或网络，所有数据只保存在本机。

## 2. 核心体验

### 桌面便签

- 应用启动后显示一张无边框纸质便签。
- 便签可以拖动，位置会自动保存。
- 当天选中几句，便签就从上到下展示几句，并根据内容自动增高。
- 多句话之间使用轻微分隔线，每句话左侧显示小勾。
- 右上角的“•••”按钮打开管理窗口。
- 默认表现为桌面小组件，不遮挡普通应用窗口；用户可以在设置中开启“始终置顶”。
- 没有选中任何语录时，便签显示温和的空状态，并提供“选择今日语录”入口。

### 管理窗口

管理窗口采用 Apple 原生视觉语言：SF 系统字体、系统蓝、毛玻璃标题栏、分段选择器、分组列表和原生表单控件。窗口包含三个页面：

1. **今日展示**
   - 展示语录库中的所有语录。
   - 每条语录左侧有圆形勾选控件。
   - 可以勾选一句或多句，也可以暂时全部取消。
   - 已选语录可以拖动排序，桌面便签按该顺序展示。
   - 今日选择不会在零点自动清空；新的一天默认延续上一组内容，直到用户重新选择，避免桌面便签意外变空。

2. **全部语录**
   - 显示永久保存的全部激励语录。
   - 可以新增、编辑和删除语录。
   - 新增语录只进入语录库，不会自动加入今日展示。
   - 删除已选语录时同时从今日展示中移除，并在删除前确认。

3. **纸张外观**
   - 纸张颜色：暖黄、柔粉、浅绿、浅蓝、米白。
   - 纸张纹理：横线、圆点、方格、纯色。
   - 选择后立即更新桌面便签，并自动保存。
   - 颜色和纹理可以自由组合。
   - 页面提供实时缩略预览。

### 新增语录

- 管理窗口右上角使用系统蓝的“＋ 新增语录”按钮。
- 点击后弹出原生编辑浮层。
- 输入内容后可以保存或取消。
- 空内容不能保存；过长内容会提示用户，但不强制截断。

## 3. 视觉方向

### 管理窗口

- 接近 macOS / iPadOS 原生应用，而不是网页后台。
- 使用 `-apple-system` / SF Pro 与系统动态颜色。
- 背景使用 macOS 分组表单的浅灰色，内容用白色圆角分组。
- 强调操作使用 Apple 系统蓝，不使用大面积黑色按钮。
- 控件支持系统深色模式和浅色模式。
- 窗口保留标准 macOS 红黄绿控制按钮。

### 桌面便签

- 采用用户确认的“阳光手写便签”方向。
- 暖黄为默认纸张，带轻微横线纹理、柔和阴影和很小的旋转角度。
- 文字清晰优先，不使用难读的手写字体。
- 纸张颜色改变后，文字颜色自动切换为有足够对比度的深色。

## 4. 技术架构

应用使用 SwiftUI 实现主要界面，并通过 AppKit 控制桌面便签窗口。

### 模块

- `AppShell`：应用生命周期、管理窗口和菜单命令。
- `DesktopNoteWindow`：无边框便签窗口、拖动、窗口层级和位置恢复。
- `QuoteLibrary`：语录的新增、编辑、删除和排序。
- `TodaySelection`：今日勾选状态与展示顺序。
- `AppearanceSettings`：纸张颜色、纹理和始终置顶设置。
- `LocalStore`：本地数据读取、校验和原子写入。

这些模块通过可观察的应用状态通信，界面不直接读写磁盘。

### 数据模型

`Quote`

- `id: UUID`
- `text: String`
- `createdAt: Date`
- `updatedAt: Date`

`AppData`

- `quotes: [Quote]`
- `selectedQuoteIDs: [UUID]`，数组顺序就是桌面展示顺序
- `paperColor: PaperColor`
- `paperTexture: PaperTexture`
- `windowPosition: CGPoint?`
- `alwaysOnTop: Bool`
- `schemaVersion: Int`

## 5. 数据保存与异常处理

- 数据以 Codable JSON 保存在用户的 Application Support 目录。
- 每次修改后自动保存，写入采用临时文件替换，避免中途退出破坏主文件。
- 首次启动内置三条示例激励语，并默认选中一条，让用户立即看到效果。
- 读取失败时保留损坏文件的备份，加载安全默认值，并向用户显示可理解的恢复提示。
- 如果选中列表包含已经删除的语录 ID，启动时自动清理。
- 不做云同步、登录、历史日历或跨设备共享。

## 6. 可访问性

- 所有按钮和勾选控件都有 VoiceOver 标签。
- 支持键盘导航、回车保存和 Escape 取消。
- 遵循系统“减少动态效果”设置。
- 颜色不是唯一状态提示；选中状态同时使用勾号。
- 管理窗口支持系统文字缩放，便签正文保持可读的最小字号。

## 7. 验收标准

1. 用户可以新增、编辑、删除并永久保存语录。
2. 用户可以从全部语录中选择零句、一句或多句作为当前桌面展示内容。
3. 用户可以调整已选语录的顺序，桌面便签同步更新。
4. 桌面便签会根据语录数量和长度自动调整高度。
5. 用户可以自由组合五种纸张颜色与四种纹理，修改立即生效并在重启后保留。
6. 便签位置与“始终置顶”选项在重启后保留。
7. 管理窗口使用 Apple 原生控件语言，并适配浅色和深色模式。
8. 应用完全离线可用，重新启动后不会丢失数据。

## 8. 验证计划

- 单元测试：数据增删改、选择多句、排序、删除已选语录、外观设置和持久化。
- 恢复测试：空数据、损坏 JSON、未知版本和失效语录 ID。
- 界面测试：首次启动、新增语录、每日多选、拖动排序、切换纸张样式和空状态。
- 手工测试：便签拖动、窗口层级、重启恢复、深色模式、VoiceOver 和不同长度的中文文本。

## 9. 本期不做

- iPhone / iPad 版本。
- iCloud 或其他云同步。
- 每日选择的历史记录和日历回顾。
- 自动轮播、随机推荐或定时更换语录。
- 分享图片、社交功能和在线语录市场。
